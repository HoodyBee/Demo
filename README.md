# Les Maisons de Champagne de l'Aube

Petit site (HTML, CSS, JavaScript simples) qui référence les maisons de champagne
de l'Aube, classées par zone (Côte des Bar, Montgueux, Villenauxe-la-Grande) puis par village.

## Fichiers
- `index.html` : la structure de la page
- `style.css` : l'apparence (couleurs, mise en page, mobile)
- `data.js` : **la liste des maisons, le seul fichier à modifier pour ajouter ou corriger une maison**
- `app.js` : le programme (recherche, filtres, affichage)

## Publier avec GitHub Pages
Settings → Pages → Source : « Deploy from a branch » → choisir la branche et le dossier `/ (root)`.
